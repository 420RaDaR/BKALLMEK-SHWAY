بكلمك شوي — نسخة ويب تجريبية 0.3

موجود الآن: مكالمة فردية، إرسال واستقبال الصوت، مؤشر الطرف المتحدث، جهات الاتصال، خيارات الضغط / التشغيل بضغطة / الحديث الحر، اختيار تنبيه الرنين والاهتزاز أثناء فتح الصفحة، مظهر فاتح وداكن، حفظ التسجيلات محليًا مع حد Free تجريبي 3 مرات × 30 ثانية.

مهم: لم يتم تنفيذ APK أصلي، استقبال مكالمات والصفحة مغلقة، زر الصوت الجانبي، المكالمات الجماعية، حسابات الاشتراك والدفع، أو لوحة التحليلات بعد. حدود Free محلية فقط ويمكن تجاوزها بمسح بيانات المتصفح. لا يعتبر ذلك نظام اشتراك إنتاجيًا.

للنشر على GitHub Pages: ارفع محتويات هذا الملف المضغوط (الملفات الخمسة) إلى جذر المستودع. لا ترفع ZIP نفسه. افتح الرابط على الجهازين وحدث الصفحة تحديثًا كاملًا.

توجد اعتمادية على PeerJS العامة وقد يتطلب الاتصال الفعلي شبكة ملائمة أو خادم TURN. لا توجد رسوم مضافة من جانبنا، لكن الخدمة العامة ليست ضمانًا تجاريًا.
